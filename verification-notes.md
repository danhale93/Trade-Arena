# Manual MetaMask Connection Controls Verification

Desktop and mobile previews both show the MetaMask Agent status badge next to a compact power control in the header. The desktop view renders the full `RECONNECT` action beside `AGENT DISCONNECTED`. The mobile view keeps the status badge and icon-only action on the same header row while the mini-widget and auth controls wrap without clipping. During the mobile capture the status temporarily displayed `AGENT CHECKING` while the status query loaded, which is the intended loading state.
