# Google Stitch Visual Reference Findings

Source: https://stitch.withgoogle.com/preview/3558629381483827872?node-id=9b00f8e6081143cdac3cea87bf54a8b9

The shared Stitch node renders a compact mobile-first interface titled “Sonic Slots” inside a tall phone frame. Its visual system uses a very dark charcoal/near-black surface, cool gray outer frame, bright blue-violet primary action button, blue accent icons, muted gray text, rounded cards with subtle borders, and a restrained neon accent palette across game symbols. The composition is centered and vertically stacked with a strong top title row, a prominent current-status card, a framed primary interaction area, a large rounded CTA, a history card, and a bottom navigation bar with a circular highlighted center action.

The transferable cues for Trade Arena are: mobile widget-first composition, dark layered surfaces, rounded elevated cards, soft gray outlines, cool blue/lilac CTA treatment, compact uppercase status labels, and a fixed bottom action/navigation treatment. The Stitch visual is a slot-game UI rather than a trading dashboard, so its domain-specific symbols and copy should not be copied; the Trade Arena controls, owner gating, wallet balances, and logs must remain intact.

The preview also shows a Stitch disclosure banner stating that the content was generated by a Stitch user and should not receive sensitive information. No direct export asset was provided by the preview; the intended implementation is a visual translation of the reference rather than a copied screenshot or external asset.
